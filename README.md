# 雨雪と浮上（YMM4Rainfall）

雨、雪、泡、カスタムPNGを映像へ重ねる、ゆっくりMovieMaker4用の映像エフェクトです。

## 導入と使い方

プラグインと対応ソースは[ダウンロードページ](https://www.mine-blog.tech/ymm4-rainfall/)から入手できます。

配布物の `.ymme` から導入する手順、DLLを手動で配置する手順、エフェクトの追加方法、設定範囲と制限は[Web版ユーザーズマニュアル](https://www.mine-blog.tech/ymm4/ymm4-rainfall-user-guide.html)を参照してください。対応ソースZIPには[HTML版マニュアル](docs/ymm4-rainfall-user-guide.html)も含まれています。

動作を確認した環境は YMM4 Lite 4.56.1.0 です。他の版での動作は未確認です。

## ソースコード

ソースのビルド方法は[ビルド手順](docs/BUILDING.md)を参照してください。
